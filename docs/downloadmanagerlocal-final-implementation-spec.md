“沿用原样式”指沿用现有主题、配色来源、导航视觉、图标体系与宿主弹窗，不是禁止用户后来明确要求的紧凑化与统一布局。

## 1. 审核结论与冲突消解

| 审核项 | 本版唯一执行结论 |

| 文字级内统一 | 同角色在所有模块字号、字重、行高、基准颜色一致；风险只改变语义色，不另起字号 |

### 直接核对过的源码事实

- `frontend.v3/downloadmanagerlocal/src/components/Config.vue::saveConfig()` 目前仅 `emit('save', payload)`；组件事件为 `save/close/switch`。所以不能凭源码认定“保存关窗是冒泡导致”，须核对宿主处理器。
- `frontend.v3/downloadmanagerlocal/src/components/Page.vue` 目前仅声明 `close/switch`，顶部“设置”发 `switch`。新增“查看数据”优先复用现有双向切换契约，参数含义先核实。
- `Config.vue::subTabs` 仍有转移 `seed_basic`、H&R `hr_advanced`、自动删种 `remover_conditions`。本版是待实施目标，不是现状。
- `plugins.v3/downloadmanagerlocal/modules/hr/service.py` 的纳管判断包含 `torrent_data.hit_and_run OR 标签命中 OR rule.hr_active`。因此 `hr_active` 不是“是否启用全局考核值”；不能继续用“启用全局规则”解释它。
- 当前 `Config.vue` 的 `tag_enabled` 默认 true。示意图中的开关状态不能作为改默认值授权。

### 审核分类

本轮必须修复：上述语义冲突、标签扫描副作用、旧规则被扩大、清记录破坏关联、H&R 解除后删除失败、保存误关窗、重复提示与文字不统一。

## 2. 文字、颜色、控件和布局的统一规范

### 2.1 文字层级表

下列是实施目标值，不是宣称现状已达到。单位 CSS px；主题色引用 Vuetify CSS 变量，不写死浅/深色值。

| 角色 | CSS token 建议 | 字号 | 字重 | 行高 | 基准颜色 |
| --- | --- | ---: | ---: | ---: | --- |
| 页面/弹窗内容主标题 | `--dm-text-title-*` | 16 | 600 | 24 | on-surface |
| 区块标题、折叠区标题 | `--dm-text-section-*` | 14 | 600 | 20 | primary |
| 字段名、开关名 | `--dm-text-label-*` | 14 | 400 | 20 | on-surface |
| 输入值、表格正文、展开正文 | `--dm-text-body-*` | 14 | 400 | 20 | on-surface |
| 表头 | `--dm-text-table-head-*` | 12 | 600 | 18 | on-surface 次要色 |
| 按钮文字 | `--dm-text-button-*` | 13 | 500 | 20 | 继承按钮语义色 |
| 徽标文字 | `--dm-text-badge-*` | 12 | 500 | 18 | 继承徽标语义色 |
| 字段帮助、区块说明、空态说明、时间元信息 | `--dm-text-help-*` | 12 | 400 | 18 | on-surface 次要色 |
| 风险/校验错误说明 | 复用 help 级别 | 12 | 400 | 18 | warning / error |

约束：

- 每一级在 Config、Page、任务弹窗及新公共组件内一致；不是把所有文字强制设成一个字号。
- Tab 和主导航保持原文字样式，不纳入此轮统一覆盖；不能 `.dm-config * {font-size:...}`。
- 同一级别不能因“某模块更重要”另加内联字号/字重。数字突出使用统一指标角色，不临时放大某张卡。
- 次要色通过同一个公共变量定义，所有同类说明共用；禁用态使用同一 disabled token。
- Vuetify 浮动标签的缩放变换保留，验收要比较同状态标签（空值/浮动），不能为凑字号破坏浮动定位。
- 允许代码/hash/路径用等宽字体，但保持所在角色字号与行高。
- 公共样式只作用于插件根类及本插件子组件。抽组件时处理 `scoped` 边界，不依赖父 scoped 样式穿透成功。

### 2.2 短名称词典

| 原含义 | 显示名 | 补充帮助（必要时） |
| --- | --- | --- |
| 各模块下载器选择 | 下载器 | 未选行为按模块说明 |
| 观察模式含解释 | 观察模式 | 只预览，不执行写操作。 |
| 下载入列触发重命名 | 入列触发 | 无需重复说明 |
| 定时补查周期 | 补查计划 | 无 |
| 历史补全周期 | 补全计划 | 无 |
| 路径关键词开关 | 分类方式 | TMDB 识别 / 路径关键词 |
| 允许为错误删除申请解除 | 允许解除 H&R | 仅对命中错误条件的删除生效。 |
| 全局规则 hr_active | 强制纳管 | 将适用范围内任务按本规则纳管。 |
| 保存配置 | 保存 | 不自动关闭 |
| 回数据页 | 查看数据 | 不隐式保存 |

字段标签保留有区分度的词，不能把源/目标下载器都简化为无法区分的“下载器”。单位保留括号。输入格式放帮助而不拼进标签。

危险操作必须保留对象：删除任务 / 删除任务及文件 / 清理记录 / 清空策略；不能全部缩成“清理”。代码标识符、API、配置键、历史日志不随文字改名。

### 2.3 三类说明与颜色

- 字段帮助：字段下方、help 级别，说明留空/0/格式。
- 区块说明：标题下方、同一 help 级别，尽量一句；详细说明折叠在“说明”。
- 风险提示：warning 图标 + help 级别橙色，相关危险选项选中才出现；正常校验错误用 error 红色和字段错误区。
- 普通编辑/添加/移除未保存行：primary 或中性；观察与授权风险：warning；真正破坏性操作的确认：error。
- 已启用图标 primary，已禁用图标灰色；故障独立 error 徽标，观察独立 warning 徽标。
- 不把普通功能开关全部涂绿色，不用成功色代替“已启用”。
- 不混用多种大块蓝色说明框、任意 title 悬停长文、不同字号提示。确有运行故障的 Alert 可保留，但不作为普通帮助。
- 不只靠颜色表达状态；有可访问名称/文字/图标提示。

### 2.4 密度与排布

- 常规单行输入目标高度 40px（允许组件内 36–40px）；按钮 32px；多行文本框按内容保留高度，不强压成单行。
- 短数值框宽 120–160px，建议 144px；普通字段 1–2 列，短字段/开关按内容宽 1–3 列，长模板/路径整行。
- 简单开关左标签右开关，按内容宽自适应，不为每个开关预留巨大等宽列。
- 宽屏同行、窄屏自然换行；不得出现页面级横向溢出。表格自身可横向滚动。
- 同级区块间距统一 16px，字段组行/列间距统一 12px；沿用现有主题细边框与 8px 轻圆角，不叠内外双层套框。
- 输入区与其帮助作为整体对齐，不靠给每个控件写不同 margin 修补。
- 页脚位于内容滚动区外，始终可达；低高度窗口亦不可遮挡输入或按钮。

### 3.1 导航清单

| 模块 | 最终子页 |

| 转移做种 | 基础设置 / 任务列表 |
| H&R 管理 | 基础设置 / 站点规则 |
| 自动删种 | 基础设置 / 错误种子清理 |
| 失败清理 | 基础设置（单页） |

调整内容归属，不改变 Tab 视觉。旧子页入口须映射到新位置，不能留下无内容 Tab 或失效跳转。

### 3.2 转移做种

基础：运行（启用/观察/通知）→ 触发执行（延迟/兜底与间隔/暂停源/扫描上限）→ 转移后重命名 → 做种校验（自动开始/跳过校验/检查间隔/最长等待）→ 全局风险默认（删源/删重复，均关）。

任务列表：每组任务一行，名称/状态/源→目标/路径/筛选/生效设置/操作。任务编辑弹窗：路线、路径映射、筛选、目标属性、风险覆盖。

- 删除源、删除重复增加全局默认；新任务有“继承/开启/关闭”三态，显示来源及生效值。建议新键 `transfer_delete_source_default`、`transfer_delete_duplicate_default`；实施时登记到后端、前端、重置键集合。
- 旧任务原有布尔值保留为明确覆盖；旧任务缺失值按升级前实际默认解释，不自动变成继承全局。新任务才默认继承。
- 不更改 `transfer_tasks` 外层 JSON 字符串保存契约；不得因三态解析使用 `bool('false')` 等错误转换。
- 弹窗“应用”只更新配置表单，主“保存”才落盘。取消不写配置。
- 移除任务配置不删除种子/文件、不伪装取消已有在途事务。
- 下载器连接扩展沿用现有专属入口，禁止在每个任务复制凭据输入；实施前定位该入口并保留能力。
- 转移后重命名仍只使用当前已支持的目的端显示名语义，不改磁盘文件。

### 3.3 H&R 管理

基础：管理与删除保护合并总开关、观察、通知模式、下载器、站点范围、任务发现与状态检查。

“更多设置”折叠：排除标签/分类、H&R 标签、刷流集成、记录保留等现有低频项；不因折叠而删除功能。

站点规则：全局基准（时长/考核期/额外时长/分享率/上传倍数/量比较/强制纳管）＋站点预设/自定义规则，保留继承、体积分档、原始 YAML。继承字段显示全局生效值，不把未设置写成 0。

- `hr_active` 文案按第 2 节纠正，不改变 OR 纳管语义。
- 旧配置管理开、删除保护关是兼容特殊状态：不得打开页面或保存其他模块时自动变为保护开。显示“旧版保护配置”短提示，保留原值，等用户显式统一；不能用两个新总开关把方案绕回原状。
- 全新配置按已合并语义运行；保存新总开关时，后端旧键兼容更新必须有测试。
- 下载器/站点用已有选项的可搜索多选，保存值保留原 API 约定的名称，不擅自换成 ID。

### 3.4 自动删种

基础设置：启用/观察/通知、下载器、仅 MoviePilot 任务、动作/计划、普通规则。动作保留暂停/删除任务/删除任务及文件。更多条件、连带同名同大小处理折叠。

错误种子清理：启用错误清理、错误关键词、允许解除 H&R。共用基础的动作、下载器与计划，不重复设置。两个新开关默认关，关键词无擅自填入的示例默认。

普通规则及连带对象逐个遵守 H&R；仅错误删除分支允许按明确授权申请解除，暂停不能解除。

不能把普通规则的多值数值直接拆成互不相关的 chips：若原逻辑按索引配对，使用“一行一组”编辑，保持原 AND/OR 与多值语义。

### 3.5 失败清理

单页：运行开关/观察/通知 → 重复残留巡检（开关、计划、保留小时）→ 简短处理说明。

默认：模块关、全新观察开、通知开、重复残留开、`0 */2 * * *`、6 小时。关闭重复巡检只禁用对应配置，不影响整理失败事件；保留时长仅作用重复残留。

H&R 只查询不解除。真实模式显示一行风险：可能删除源文件及下载历史。

### 3.6 种子重命名

基础：启用/观察/通知/下载器；入列触发与防抖；定时补查与计划。开关关闭只禁用关联字段，不清值；定时开启才要求有效计划。

模板与过滤：电影/电视剧模板各占整行；“可用变量与示例”折叠；包含/排除标签 chips；目录与 hash 白名单逐行输入，置“更多过滤”。保留旧白名单匹配语义，不从标签名猜含义。

只改下载器显示名，不改磁盘文件。观察不改名、不推进重试/归档。已存模板原文不重排、不去空格、不按逗号切分。

### 3.7 分类与标签

基础：启用/观察、下载器、站点标签/剧名标签/下载分类、站点前缀、补全计划；标签删除权限折叠并用风险语义。

映射规则：分类方式与前缀集中在本页；TMDB 映射和路径关键词映射二选一显示，切换不清空另一组。路径映射可改为行编辑，但原顺序/格式/匹配逻辑保持。

站点映射简为 Tracker 域名、站点映射或自定义标签、最终标签预览；保留原站点库域名、不丢未收录旧值；已识别站点与自定义标签优先级保持现状。

新配置站点前缀为 `🏠`。已有空串是合法配置，不补成默认。下载器未选沿用本模块“全部”语义，明确短提示。

### 3.8 上传限速

基础：启用/观察、下载器、新种宽限（30 分钟，0 即刻）。支持范围沿用现有 qB/TR，不声称 rt 已支持；至少选一个。

规则：下载器总上限表＋站点合计上限表。总上限正整数必填；站点空/0不设站点额度，但仍受下载器总上限。额度单位统一 `KiB/s`，数值右对齐，单位只放表头。

站点额度跨所选实例共享；宽限期仍受总上限。观察不调限速也不恢复已有额度。扫描站点/清空策略保留数据页；不新增通知调度，不改分配算法。删除策略行只是表单编辑，保存才生效。

## 4. 配置兼容与默认值：不得省略的测试

1. 分清：全新安装、旧配置缺键、已有显式值、主动恢复默认。不能只通过 `if not value` 判定。
2. 新装与恢复默认开启本模块观察；普通打开/升级/保存不批量开启观察。重置先改表单、保存才落盘。
3. `PANE_RESET_KEYS.transfer` 是显式集合，新键必须手工登记；其他模块也检查键归属，不能跨模块重置。
4. 不从示意图提取默认状态。未在本规格明确修改的默认，按当前后端实际默认保留。
5. 空下载器含义不同：分类标签是全部；上传限速必须选择；自动删种未选不暗中扩大。其他模块逐项核对旧行为，不统一改成全部或无。
6. 多选自由项回车添加/支持多项粘贴，不按空格拆开含空格标签；序列化为旧后端接受的格式。
7. 路径、模板、YAML 不套用标签切分逻辑；数组/字典/JSON 字符串的类型保持契约。
8. 不删除表单中非当前 Tab 的配置，不丢未知兼容键；新增 key 在 defaults、后端解析、保存、重置、测试五处对齐。

## 5. 保存、关窗与查看数据

配置页底部固定操作区：左“查看数据”，右保留明确关闭入口与“保存”。保留已有取消/关闭能力，不能只有保存却无法退出。

- 查看数据：切回插件数据视图，不运行扫描、不保存、不触发业务；若配置未保存，按宿主已有未保存处理约定，至少不能静默保存或丢弃。
- 保存：一次真实保存请求；确认成功才提示成功。不 emit close、不顺带 switch、不重建配置组件；保留当前主/子 Tab、滚动位置。
- 保存失败：窗口/输入/所在 Tab 保留，显示错误，允许重试；重复点击时防止并发保存。
- 只有显式关闭/取消或查看数据导航才改变窗口/视图；数据页其他保存动作不连带关配置窗口。
- 不能通过 `stopPropagation` 猜测修复。先读宿主 save/switch 处理器及联邦组件契约，再写集成测试。
- 若标准 save 事件在宿主必定关闭：优先使用宿主已有且文档支持的不关闭保存能力；不存在则停止该工作包，给出插件内方案与风险请用户决策。禁止改宿主、偷偷另建保存接口、伪造成功或关闭后重开。

必须覆盖：配置单独打开、数据页进入配置、保存成功/失败、保存后继续编辑、显式关闭、查看数据往返、带未保存变更的导航、数据页其他操作不关配置。

## 6. 数据页公共结构与表格状态

模块标题（图标启停色＋观察/执行/故障）→ 一行统计徽标 → 配置摘要 → 业务表格。

公共组件最小边界：`ModuleHeader.vue`、`ModuleTable.vue`、`TableState.vue`，复用 `DownloaderBadge.vue`。可以复用已有合适组件，不强制为文件数量而抽象。不建万能表单框架。公共组件只管展示，不能写 H&R 判定、统计规则或业务筛选。

- 配置摘要每组配置一行；没有分页/筛选需求时不放空工具栏。
- 单层细边框、轻圆角、紧凑表头，文字遵守第 2 节；数值右对齐。
- 详情统一行展开；确有单条动作才加操作列。批量动作在表头。
- 记录页数选择 `20/50/100`，默认20。后台先筛选再分页，切筛选回第一页；旧 `detail_limit` 兼容保留，不用诊断截断量代替记录分页。
- 窄屏沿用同一表格、容器横向滚动，不维护另一套业务卡片。
- 首次加载骨架行；刷新保留旧数据；首次失败显示错误+重试；刷新失败保留旧结果并提示。
- 空态保留标题和表头、内容区120–160px、小图标+主文案，必要时一行说明；无空分页器，0条禁用清记录。
- 区分：暂无记录 / 筛选无结果+重置 / 尚未扫描 / 扫描无候选。模块关闭且有历史仍可读，不能覆盖成空态。
- 名称优先，hash作为辅助；旧记录无名显示短 hash＋名称未记录，不临时查下载器冒充完整历史。

### 转移统计与历史

目标被真实确认完成才计成功；源删除失败不撤销成功，同事务只计一次。今日失败只在进入终态计一次，普通重试不累加。回滚中属于在途，不混入终态历史。删源未完成停在其真实阶段，不冒充完整收尾。

历史用 `history_hidden` 或等效仅展示标记；保存事务必须保留标记。新的独立转移事务可显示为新记录，不能因为同源 hash 永久隐藏。不得破坏源→目标索引供同步删除使用。普通手动执行可能重试已放弃任务，确认说明必须准确。

### H&R 与清理

缺失清理前下载器读取必须成功；读失败不等于不存在。普通清记录不是授权解除。清显示记录不重置统计/重试/保护/恢复状态。

新增逐条结果从真实动作出口登记，不从候选推导成功。新增展示历史固定容量每模块最多1000条，批量保存避免每颗重写全量；不把此上限套到已有安全状态或转移来源索引上。

保留旧任务#67的明确目标：重命名归档自动保留最新1000条，超出裁掉最旧展示记录；先核对archive状态是否参与“不自动重试”判定，裁掉展示记录不能把旧失败对象重新纳入自动重试。需要保留既有最小重试/归档状态依据，而不是为凑上限删除安全状态。补1000/1001、时间缺失/同时间稳定排序、重载后上限、恢复/删除契约测试。实现归入P5。

旧通知与调度盘点、历史Astra报告未闭合问题不是已完成：开工核对报告逐条映射P0–P8，有触发条件再修；保留独立复核，避免重复做旧版本全量审查。范围外代码清理仍为候选，不因本轮清文档自动授权。

## 8. 公共 H&R 联动与危险操作

复用 `modules/hr/guard.py` 和服务状态源，建议 `modules/hr/interlock.py` 做小型公共接口。不新增第二套名单或判定器。

- 普通自动删种/失败清理/同步删除：候选层过滤，动作前再核验；连带对象逐个检查。暂停不申请解除。
- 转移：按配置 H&R 标签门控；联动关闭时跳过，开启时可转移但不提前解除。仅真实目标校验成功且准备删源时申请解除。
- 错误清理：仅独立错误分支命中、再次确认且执行删除时，可按明确授权申请解除。
- 来源仅允许 `transfer_source` / `error_torrent_delete`，其他来源只能查询。
- H&R模块关不启动其业务；开启但故障/快照不可确认时，只阻止对应危险操作，不拖停其他模块。
- 关联模块观察不执行其解除写操作。转移/删种自身观察也禁止真实写入。
- 身份用下载器实例＋hash；解除需授权、可幂等、不能按 hash 跨实例操作。
- 跳过目标校验不等于真实校验完成，不能凭 skipverify 申请解除保护。
- 解除成功但删除失败：恢复本地保护，标签恢复失败仍保留本地保护并报告。操作中断/重启须可检查，不把重启当成功。
- 与扫描/重新纳管更新协调，防旧扫描覆盖授权结果；下载器IO不持有模块全局大锁。
- 日志分清请求/解除/删除/恢复；清历史不能删除这些在途安全依据。

三下载器错误归一必须有实际字段样本。区分本地错误、Tracker明确拒绝、临时连接故障；有效备用Tracker存在时不因另一条报错默认整种删除。无信息不得默认为错误候选。已有暂停动作不能被升级成删除。

## 9. 标签清理与限速的特殊边界

标签扫描真正只读。执行范围由后端快照确定，分页不改变对象集合；执行前复核，不将扫描后新出现的候选顺带加入。

受保护H&R标签、活动临时标签不能进入自动回收集合。取消逐项选择不代表旧人工可选集合全部自动授权。按标签名聚合，关联任务按实例＋hash去重。全局标签定义只有确认无非目标任务关联时可删，否则仅移除授权对象关联。

限速扫描站点会保存策略，不得标为只读；保存时保留已有额度。清空策略影响整个策略集，确认说明不能称仅当前页。观察模式不得调/恢复额度。不能因清历史丢掉恢复原限速的依据。

## 10. 运行总览与运行诊断（最后接线）

总览：全局四徽标（启用模块、观察模块、执行中模块、故障模块；模块计数不含标签清理独立重复项）→ 仅有问题时“需要关注”→ 模块操作卡。

刷新只读上次结果；重新检查进行新的只读检查，不能两个按钮同义。无缓存时显示未检查，不伪造结果。只读检查失败隔离到单项；远端路径无法核实标待确认，不用MP本机路径不存在判断远端失效。行展开含检查时间、原因、建议、前往设置/查看模块数据。

不放修复全部、清空异常、集中业务数据清理，不把上传限速/重命名等详情再搬回诊断。

6. 回滚优先在干净且已核对工作区使用指定提交的 `git revert <hash>`，多个阶段按依赖逆序处理；有后续依赖或脏工作区先停下来评估。禁止reset硬回退或整文件恢复抹掉其他工作。
7. 基线/阶段提交仅是本地检查点，不自动推送；版本发布、完整包与QNAP仍按P8门槛。

### P0：基线与契约核对（先不修改业务）

## 14. 取舍与验收边界

采用共享样式token与最小表格外壳，而不是重做主题：满足级内统一，又避免破坏宿主/Tab。

采用H&R唯一状态源的小型联动，而不是消息总线：当前单进程收益更明确，也少一套重建/补偿状态。

采用仅隐藏转移历史而不是物理清来源索引：索引承担同步删除与在途事务关联，展示清理不能改变业务。

采用短帮助＋折叠详情而不是大段说明框：减少密度问题；必要风险和真实校验错误仍常驻。

代价：后端契约/结果出口/宿主事件仍需真实测试，不能把本版“方案定稿”写成“功能已完成”。不确定字段或权限无法核实就停对应包，不为凑完整度伪造能力。
